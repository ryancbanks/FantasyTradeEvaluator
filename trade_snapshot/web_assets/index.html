First-time extension setup
  1. Download the extension and extract the ZIP to a folder you will keep.
  2. Open chrome://extensions in Chrome or Brave, turn on Developer mode, and choose Load unpacked.
  3. Select the extracted folder—the one containing manifest.json—then return here, refresh this page once, and click Connect extension.
  4. Open the extension from Chrome’s Extensions menu, confirm that its four-character code matches the code shown here, and choose Pair with app.
  5. Before scanning, sign in to ESPN and Yahoo normally in this same browser. Sign in to FantasyPros too when its option below is on; then close those sign-in tabs.

Microsoft Edge works too: use edge://extensions and the same steps.

What this starter corpus includes

Preseason features come from Fantasy Football Calculator 12-team PPR ADP. Weekly rosters, schedules, and realized outcomes come from nflverse under CC-BY-4.0. It does not claim historical ESPN, Yahoo, or FantasyPros projections.

Identity matches are exact—never fuzzy. Draft Lab uses one fixed preseason bye; a player-season is excluded if actual play appears during that team’s original bye. The starter corpus is for the portable standard scoring rules; review coverage before using custom scoring.
