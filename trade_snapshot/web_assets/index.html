First-time extension setup
  1. Download the extension and extract the ZIP to a folder you will keep.
  2. Open chrome://extensions in Chrome, turn on Developer mode, and choose Load unpacked.
  3. Select the extracted folder—the one containing manifest.json—then return here and click Connect extension.
  4. Open the extension from Chrome’s Extensions menu, confirm that its four-character code matches the code shown here, and choose Pair with app.
  5. Before scanning, sign in to FantasyPros, ESPN, and Yahoo normally in this same browser, then close those sign-in tabs.

Microsoft Edge works too: use edge://extensions and the same steps.

League size, every team, and every roster are detected from your signed-in FantasyPros league and cross-checked against ESPN. Paste ESPN League Home—or any page inside that fantasy-football league; only its numeric league ID is retained. Yahoo links may be league home, numeric team, Players, or Player List pages; the app safely switches Yahoo to All Players.
