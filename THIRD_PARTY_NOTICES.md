# Runtime data-source notices

The application code and the data fetched while it runs are separate works. A weekly
collection may retrieve, transform, and preserve provenance for these public datasets:

- nflverse statistics and injury-report data, published under
  [CC-BY-4.0](https://github.com/nflverse/nflverse-data/blob/main/LICENSE.md).
- DynastyProcess's `db_playerids.csv` exact-ID table, published in its
  [GPL-3.0 data repository](https://github.com/dynastyprocess/data/blob/master/LICENSE).
- Sleeper's public NFL player and trending endpoints, attributed to
  [Sleeper](https://docs.sleeper.com/).

The source URL, provider, capture time, availability, content digest, and source-response
byte count travel with each portable weekly profile snapshot. Original response bodies
are not retained in that bundle. This notice describes runtime data provenance; it does
not state or alter the license of the application source code.
